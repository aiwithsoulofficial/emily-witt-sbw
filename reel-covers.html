Instagram Reel Covers - Space Between Wellness

5 branded templates at native 1080 x 1920px (Instagram Reel / Story spec). Each cover is pre-scaled to 35% for preview. The actual pixel values inside each cover are native - so screenshots at 100% zoom or Chrome DevTools device emulation at 1080x1920 will produce a true 1:1 export.

How to export as PNG
Option A - Chrome DevTools screenshot (recommended for full resolution):
1. Open this file in Chrome. Open DevTools (F12). Toggle device toolbar (Ctrl+Shift+M / Cmd+Shift+M).
2. Set device dimensions to 1080 x 1920, DPR = 1. Scroll to the cover you want.
3. Run in console: document.querySelector('.cover-outer.t1').scrollIntoView() (change selector per template).
4. In DevTools, use "Capture node screenshot" (right-click element in inspector > Capture node screenshot).

Option B - Right-click on the scaled preview > "Save image as" (lower resolution, suitable for Canva reference).

Option C - Recreate in Canva using these files as the visual reference. All font names, hex codes, and px sizes are annotated in the source HTML.
